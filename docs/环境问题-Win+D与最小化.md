# 环境问题：Win+D / 最小化后窗口被拉回（与本项目代码无关）

> 结论：**不是校园二手交易平台的缺陷**。本机有第三方程序在窗口最小化/显示桌面后约 0.5 秒内把它拉回前台。
> 影响范围：只在**普通 Edge 窗口**出现；无痕窗口正常；其他网站正常。

## 一、现象

在普通 Edge 窗口中打开本系统：

- 按 `Win + D` → 桌面出现约 **0.48 秒**后，Edge 又被推到前台
- 点标题栏「最小化」→ 同样被拉回
- 换到无痕窗口 → **完全正常**
- 在其他网站（如 bilibili 视频页）→ **完全正常**

## 二、排查过程与证据（共四轮）

| 轮次 | 检验 | 结果 | 排除了什么 |
| :-: | --- | :- | --- |
| 1 | 代码扫描：`window.focus()` / `Notification` / 全屏 API / Keyboard Lock / iframe | 全部为空 | ❌ 页面主动抢焦点 |
| 2 | 关闭全部 21 个 Edge 扩展 | 仍复现 | ❌ 扩展 |
| 3 | 退出登录 | 仍复现 | ❌ 登录态 / WebSocket 会话 |
| 4 | 窗口样式检查：`WS_MINIMIZEBOX` 存在、`WS_EX_TOPMOST`=False、未最大化；explorer 响应正常 | 窗口本身正常 | ❌ 窗口属性 / 资源管理器故障 |
| 5 | 前台窗口监控（150ms 采样） | `explorer → msedge` 间隔 **0.48s**；静默 20s **0 次**自发切换 | 证明是"被还原"而非"抢焦点" |
| 6 | 诊断开关：`?noTimers=1` / `?noWS=1` / `?noPoll=1` / `?noNotify=1` | 全部仍复现 | ❌ 定时器 / WebSocket / 轮询 / 通知 |
| 7 | 同源静态空页 `/diag-blank.html`（0 个 `<script>`） | **不弹回** | 证明与"是否加载本应用"相关 |
| 8 | `/login`、`/search` | 都弹回 | ❌ 单个页面/组件 |
| 9 | `?bare=1`（只渲染空白 div） | 弹回 | ❌ 业务组件/布局 |
| 10 | `?bare=2`（连 Element Plus 都不安装） | 弹回 | ❌ Element Plus |
| 11 | `?bare=3`（加载 JS 包但 **不挂载 Vue**） | 弹回 | ❌ Vue 运行时/路由/Pinia |

**第 11 轮是关键**：连"Vue 一行都不执行、只把打包产物下载下来"都会触发 → 触发点不在任何一行业务代码里。

## 三、技术解释

网页在浏览器沙箱内**没有 API 能还原一个已最小化的窗口**（`window.focus()` 只能请求焦点，且本项目中不存在该调用）。
能"把窗口拉回前台"的只有 Win32 程序（`SetForegroundWindow` / `ShowWindow`）。

本机同时运行着多个具备该能力的第三方程序：

| 进程 | 说明 |
| --- | --- |
| `wallpaper32` | Wallpaper Engine 动态壁纸，**hook 桌面窗口（WorkerW）**，是"显示桌面/最小化异常"的已知元凶 |
| `LenovoTray`（窗口类名 `BlockTrayWindow`） | 联想电脑管家托盘，名称即"阻止托盘" |
| `LenovoAppStore` × 5、`LZＴray`、`LeAppStoreTray`、`LegionZone` | 联想/拯救者全家桶 |
| `SOGOUSmartAssistant` | 搜狗输入法智能助手（悬浮面板） |
| `ESurfingClient` / `wegame` / `Nahimic` | 校园网客户端 / 腾讯游戏平台 / 微星音频 |

它们很可能按"窗口是否活跃 + 页面重量"判断是否需要把窗口保持前台 —— 这解释了
"纯静态页不弹、本应用（1.1 MB JS + 140 KB CSS）弹、无痕窗口不弹"的全部现象。

## 四、规避方案（已验证可用）

| 场景 | 做法 |
| --- | --- |
| **答辩演示** | 双击 `tools\打开校园演示（无痕）.cmd`（无痕窗口，实测正常） |
| 需要回桌面 | `Win + M`（最小化全部）或 `Win + Ctrl + D`（新虚拟桌面）再切 |
| 想彻底消除 | 退出 **Wallpaper Engine** → 退出**联想电脑管家** → 必要时**重启电脑**（本次系统已连续运行 18 小时） |
