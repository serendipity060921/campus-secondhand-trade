# 接口文档说明（OpenAPI / Swagger UI）

> 校园二手交易平台 · v0.18 / 收尾⑨-1
> 依赖：`springdoc-openapi-starter-webmvc-ui` **2.3.0**（2.x 版本线对应 Spring Boot 3.2.x）

## 一、为什么引入

在此之前，接口信息散落在 `docs/test-cases.md`、README 与代码注解里 —— 能查，但不方便。
引入 springdoc 后，**全部 Controller 自动生成 OpenAPI 3 文档**：参数、请求体、响应结构、
在线试调都有，论文"系统实现"章节可以直接配图，答辩时也能当场演示。

## 二、怎么访问

```bash
# 在线文档（推荐，可展开、可试调）
http://127.0.0.1:8080/swagger-ui.html        # 会 302 跳到 /swagger-ui/index.html
http://127.0.0.1:8080/swagger-ui/index.html  # 直达

# JSON 描述（可导入 Postman / Apifox，也可作为接口契约留档）
http://127.0.0.1:8080/v3/api-docs
```

实测（2026-10-16）：

| 地址 | 结果 |
| --- | --- |
| `/swagger-ui/index.html` | HTTP 200（`text/html`，734 字节） |
| `/v3/api-docs` | HTTP 200，`openapi 3.0.1`，标题「校园二手交易平台 API」，版本 `v0.18` |
| `/v3/api-docs/swagger-config` | HTTP 200 |
| **收录接口路径数** | **53** |

## 三、两个容易踩的点（本次实测确认）

### 1. 登录拦截器**不需要**加白名单

项目用的是"注解决定是否鉴权"，而 `WebMvcConfig` 里拦截器只注册了 `/api/**`：

```java
registry.addInterceptor(loginInterceptor).addPathPatterns("/api/**")
```

因此 `/v3/api-docs`、`/swagger-ui/**` **天然不被拦截**，无需任何放行配置。

### 2. `spring.web.resources.add-mappings: false` 也**不影响**文档

项目为了"后端不提供静态资源"刻意关闭了默认静态映射（前端由 Nginx 托管）。
实测确认：springdoc 的 swagger-ui 是**自己注册资源处理器**的，因此照常可用。

## 四、部署形态下的可达性（★ 这一点既是限制也是安全性质）

经 Nginx（8081）访问 `/v3/api-docs` 会**落到前端 SPA 回退**（返回 `index.html`，411 字节），
即：

- **部署形态下接口文档不对外暴露** —— 局域网/外网通过 8081 访问不到文档，
  只有本机（服务器上的 `127.0.0.1:8080`）能打开；
- 这对生产是**好事**：接口文档本身会暴露全部路由与参数结构，属于"内部资料"。

如果确实需要在外网提供文档，得在 Nginx 里显式加一条 `location /v3/api-docs` 反代 ——
**本课题选择不暴露**，答辩演示时用服务器本机浏览器打开即可。

## 五、生产环境想关掉文档

在 `application-prod.yml` 加两行即可（无需改代码）：

```yaml
springdoc:
  api-docs:
    enabled: false
  swagger-ui:
    enabled: false
```

## 六、本项目的接口约定（已写进文档描述，读者一眼能对上）

- **统一响应结构**：`{ code, message, data, timestamp }`，前端按 `code` 分支处理；
- **鉴权**：需登录的接口标注 `@LoginRequired`，请求头带 `Authorization: Bearer <token>`；
  公开接口是"可选鉴权"（带 Token 能识别身份，不带也能访问）；
- **限流**：`@RateLimit` 标注的接口超限返回业务码 `429`；
- **内容机审**：发布商品先过机审（违禁词→拒绝；联系方式/价格异常→转人工复核），结论落库。

## 七、论文里怎么用

1. 在"系统实现"章节插一张 Swagger UI 截图（`docs/test-evidence/接口文档-swagger-ui.png`）；
2. 配文说明："后端接口通过 springdoc 自动生成 OpenAPI 3 文档，共收录 **53** 个接口路径，
   支持在线查看与调试；文档在部署形态下不对外暴露（仅服务端本机可达）"；
3. 把 `/v3/api-docs` 的 JSON 作为**接口契约**附在附录里（比手写接口表更准确、可复算）。
