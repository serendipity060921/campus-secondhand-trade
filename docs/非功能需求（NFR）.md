## 一、需求条目（原 US-QUALITY / US-SEARCH-03 / US-EVAL-03）

### 质量与非功能需求（US-QUALITY）

> **归类说明**：本节 9 条（US-QUALITY-01~07、US-SEARCH-03、US-EVAL-03）严格归类为**非功能需求**，用故事格式书写只为纳入优先级与追溯；
> 它们的验收对象不是界面，因此**不产生浏览器场景与截图**，也不写入《用户故事报告》。

> 这一组是**跨功能的非功能需求**，也是本项目测试与质量工程的主要对象。

### US-QUALITY-01 接口权限与越权防护 【必须】
**作为** 平台方，**我希望** 任何写操作都必须校验身份与归属，**以便** 防止越权操作与信息泄漏。

**验收标准**
- AC1　Given 我未登录 / When 调用任何写接口 / Then 返回 401，操作不生效。
- AC2　Given 我登录为普通用户 / When 调用管理员接口 / Then 返回 403。
- AC3　Given 我登录为普通用户 / When 操作**他人**的订单/商品 / Then 被拒绝，数据不变。

**对应测试**：权限越权 6 条 + 部署验证 D10/D24　**相关缺陷**：BUG-01、BUG-02（均已修复）

### US-QUALITY-02 页面三态完备（加载/空/错误）【应该】
**作为** 用户，**我希望** 每个页面在加载中、无数据、请求失败时都有明确反馈，**以便** 不会面对空白页不知所措。

**验收标准**
- AC1　Given 数据正在请求 / When 页面打开 / Then 显示加载态（骨架屏或加载提示）。
- AC2　Given 请求返回空列表 / When 页面渲染 / Then 显示空状态文案与引导。
- AC3　Given 请求失败（如后端未启动）/ When 页面渲染 / Then 显示错误态与重试入口，**不是白屏**。
- AC4　Givne 全部页面 / When 运行 `tools/check-states.py` / Then 20 个页面全部达标、缺失数为 0。

**对应测试**：`tools/check-states.py`（CI 中运行）、部署验证 D3~D5　**相关缺陷**：BUG-16-05（非法模板组合与失效绑定，已修复）

### US-QUALITY-03 界面视觉一致（设计令牌）【可以】
**作为** 平台方，**我希望** 所有颜色、间距来自统一的设计令牌，**以便** 视觉一致且便于统一调整。

**验收标准**
- AC1　Given 前端全部源码 / When 运行 `tools/check-tokens.py` / Then 裸色值数量为 0（CI 中锁定为 0）。

**对应测试**：`tools/check-tokens.py`　**相关缺陷**：无

### US-QUALITY-04 可访问性与对比度 【应该】
**作为** 有视觉或操作障碍的用户，**我希望** 文字对比度达标、键盘可操作、图片有替代文本，**以便** 正常使用平台。

**验收标准**
- AC1　Given 全部页面 / When 运行 `tools/ui-a11y.py` / Then 对比度不达标项为 0（装饰性文字除外）、焦点可见、图片均有 alt。
- AC2　Given 我只用键盘 / When 浏览并操作主要流程 / Then 所有可点击元素均可到达并触发（无鼠标独占元素）。

**对应测试**：`tools/ui-a11y.py`、`tools/check-states.py`（鼠标独占 0）　**相关缺陷**：BUG-16-04（对比度回归 3 → 15 处，已修复）

### US-QUALITY-05 窄屏可用（手机浏览）【应该】
**作为** 用手机浏览的同学，**我希望** 页面在 390px 宽度下不出现横向溢出，**以便** 正常查看与操作。

**验收标准**
- AC1　Given 前台页面 / When 视口宽度为 390px / Then 无横向滚动条，核心操作可完成。
- AC2　（已知例外）管理后台侧栏固定宽度，窄屏会溢出；**经评估不做适配**，已记录在测试报告的遗留问题中。

**对应测试**：`tools/capture-ui.py` + 人工走查　**相关缺陷**：无

### US-QUALITY-06 热点数据缓存与限流 【应该】
**作为** 平台方，**我希望** 热点接口有缓存、高频接口有限流，**以便** 保证系统在高并发下可用。

**验收标准**
- AC1　Given 商品列表/详情/分类/推荐接口 / When 重复请求 / Then 命中缓存（Redis），响应时间显著下降。
- AC2　Given 缓存中不存在的数据被反复请求 / When 请求 / Then 空值缓存生效，不压垮数据库（防穿透）。
- AC3　Given 同一 IP 高频调用登录接口 / When 超过阈值 / Then 返回限流提示（本项目对**本机同样生效**，需专门测试）。

**对应测试**：部署验证 D12/D17/D18、压测脚本 load-test.py　**相关缺陷**：无

### US-QUALITY-07 缺陷可追溯与质量不退化 【必须】
**作为** 项目维护者，**我希望** 每个缺陷都有记录、每次改版都不让质量指标倒退，**以便** 长期维护。

**验收标准**
- AC1　Given 发现任何缺陷 / When 登记 / Then 记录发现方式、复现步骤、根因、修复与验证结果。
- AC2　Given 代码推送 / When CI 运行 / Then 三类静态检查与三套测试自动执行；指标超过阈值则失败（棘轮机制）。

**对应测试**：`.github/workflows/ci.yml`、`docs/defect-log.md`　**相关缺陷**：全部 12 条缺陷均按此流程闭环
