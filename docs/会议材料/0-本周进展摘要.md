## 四、TDD 过程中暴露的两次"需求理解错误"（最有价值的部分）

1. 我把"确认收货"限定为只有买家 → 与 `US-ORDER-03`（"作为**卖家**…确认交易完成"）冲突 → **改规则不改需求**
