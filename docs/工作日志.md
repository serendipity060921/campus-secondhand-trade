### 4. ★ CI 连续失败的真正原因（第四层调试）

- 根因：两个 job 无 job 级 `working-directory`，`./mvnw` 在仓库根 → command not found
- 修复：该步加 `working-directory: backend` → **run #192 五个 job 全绿**（含部署验证 D1–D28）
- 记录：`docs/CI自动化说明.md` §二「第四层」
- 提交：`9fb33db`

- 自检脚本报"裂图 55 张"，实为 `loading="lazy"` 未滚到视口 → **自检脚本也会说谎**
- `spec.md` 图里把「待收货(2)」写成「待交货(2)」→ 被我写的回读校验抓到
- `Get-Content` 在 **CRLF/LF 混排** 的文件上把 CHANGELOG 的 197 行数成 89 行，
  一度以为写入时丢了内容；用 `git show --numstat`（38 加 / 0 删）与 Python `splitlines()` 才确认完好
  → **统计工具在混合换行符上不可靠**，判断"有没有丢内容"要看 diff 的增删数，不是行数
