## 二、为什么用 Excel 原生图表，而不是贴图片

1. **可编辑**：论文里想改配色、字号、坐标轴标题，双击就行，不用回到代码；
2. **随数据更新**：重跑生成器后图表自动跟着新数据走（覆盖率那条曲线还会继续变长）；
3. **可复制进 Word**：选中图表复制粘贴即可，仍是矢量图，打印不失真。

> 本机 Python 环境里没有 matplotlib，因此没有走"代码画 PNG"的路线 —— 对论文配图来说，
> 原生图表反而是更好的选择。

## 三、怎么贴进论文

| "质量保障"章节 | 测试用例分布 + 缺陷统计 |

## 四、生成与校验

```bash
# 生成（覆盖写入 docs/论文图表包.xlsx）
python tools/gen-paper-figures.py

# 结构校验（ZIP/XML 完整性、工作表与单元格统计）
<python> <office-skills>/scripts/check_office.py docs/论文图表包.xlsx --out checks.json
```

生成器自带**交叉核对**：会按章节统计缺陷条数，并与 `docs/缺陷跟踪表.md` 统计表里声明的数字比对，
不一致就打印警告 —— 本次正是靠它发现缺陷表自己的统计数字漏更新（补了 BUG-017 却没改"10 项"）。

## 五、已知限制（如实说明）

1. **LibreOffice 预览渲染不出表格与图表内容**：用办公技能自带的渲染器导出预览图时，
   只渲染出顶部标题、正文区域为空。按该技能的规定，这类现象判定为**渲染器失败**，
   而不是文件有问题 —— 因此本项目以**结构校验 + openpyxl 读回**作为交付依据
   （结构校验 `verdict: pass`，读回确认 8 个工作表、6 个图表对象均存在）。
   在 Excel / WPS 中打开应正常显示；如你本地打开发现异常，请把截图发我。
2. **数据是快照**：图表反映的是生成时刻的实测结果；数据变化后需重跑生成器。
3. **机审按天趋势目前只有 2 天**：因为 `moderation_log` 是 v0.18 新表，
   真实数据从接入机审落库那天才开始积累，趋势图会随使用天数增长。
